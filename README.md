 🛒 MERN E-Commerce Website

A full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js).

Users can browse products, place orders, and manage their profiles.

 🚀 Features

1. User Registration and Login
2. User Authentication using Sessions
3. Browse and Explore Products
4. Place Orders
5. User Profile Management
6. Address Management
7. Responsive User Interface

 🛠️ Tech Stack
 Frontend
- React.js
- JavaScript
- Tailwind CSS
- HTML5
- CSS3

 Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Express Session

 Tools & Platforms
- Git & GitHub
- VS Code
- MongoDB Atlas
